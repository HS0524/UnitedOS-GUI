# UnitedOS

UnitedOS is a desktop utility application written in Java and Swing. It brings several small productivity and learning tools together behind a sign-in screen.

## Demo
 - [text](https://drive.google.com/drive/folders/133htcgfDWfi7_8V8i_gMr2FVxb6NdTWg?usp=drive_link)

## Features

- User account creation, sign-in, and account management
- Basic and scientific-style calculator interfaces
- GPA calculator
- Planetary weight calculator with space imagery
- Text encryption and decryption utility
- Page availability controls for administrator accounts
- English, Spanish, and French interface text in supported screens

The application opens at the login screen. Some tools and administration controls depend on the account role and the local page configuration.

## Requirements

- JDK 22 (the project uses Java 22 source/target settings and preview features)
- Apache Ant, or NetBeans with Java SE project support

## Build and run

This repository is a NetBeans/Ant Java project. From the project root, build it with:

```sh
ant clean jar
```

Run the packaged application with:

```sh
java --enable-preview -jar dist/UnitedOS.jar
```

The project can also be opened directly in NetBeans using `nbproject/project.xml`. The configured main class is `physicsGUI.Login_Interface`.

The required `kotlin-onetimepassword-2.4.1.jar` dependency is kept in the repository root and included on the Ant/NetBeans classpath. The GUI forms in `src/physicsGUI/*.form` are NetBeans GUI Builder source files and should be kept alongside their Java classes.

## Runtime files and privacy

The application reads and writes files relative to its current working directory. Account data and its encryption key are local runtime files and should not be committed or shared:

- `AccountManagerAES.txt` — encrypted account records
- `secretKey.key` — AES key used by the current account-storage implementation
- `AccountManager.txt` — legacy/plain account data used by some administration screens
- `pageManager.txt` — enabled/disabled page settings
- `GPA.txt` — GPA calculator data

These files are excluded by `.gitignore`. A fresh checkout starts without local account data; account creation and other features initialize their files as needed. Back up the key and encrypted records together if you need to retain local accounts. Losing or replacing the key can make existing encrypted records unreadable.

## Project layout

```text
src/physicsGUI/   Swing screens and application utilities
src/images/       Image assets used by the interfaces
resources/        NetBeans resource source root
nbproject/        NetBeans project configuration
build.xml         Ant build definition
manifest.mf       JAR manifest settings
```

`build/` and `dist/` are generated by Ant and are excluded from version control. The source tree, GUI forms, image assets, project configuration, manifest, and required dependency are the files needed to build and distribute the application.

## Notes

- Run the application from the project root when using the source build so its relative runtime file paths resolve as expected.
- `--enable-preview` is required by the current project configuration.
- The repository does not currently define an automated test suite.
